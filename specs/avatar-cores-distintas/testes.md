# Teste manual: avatares com cor distinta

1. Crie uma família e entre com 3 contas novas pelo código de convite.
2. Em **Família**, confira que os 4 membros têm cores diferentes.
3. Em **Gastos**, lance um gasto com cada conta. Na listagem, cada avatar deve ter uma cor própria.
4. Uma conta sai da família e entra de novo: deve receber uma cor que ninguém mais usa.
5. Migração (ambiente com dados antigos): famílias que tinham cor repetida passam a ter cores distintas.
   O membro mais antigo de cada cor mantém a sua; só os repetidos mudam.
